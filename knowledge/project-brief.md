# Project Brief — Original Context

Build the full fantasy football auction draft platform end-to-end per the design documents (PRD, data-model, state-machine-flows). The system conducts a real-time salary-cap auction draft for a 12-team private fantasy football league, with server-authoritative bidding, post-draft ESPN roster transfer, and optional Auto-Agent mode. Implementation follows the phased build plan in BUILD_PLAN.md: phases 0–5 and 7 as the sequential core, with phases 2b, 6, 8, 9, and frontend screens parallelizable once the core API/schema is frozen.
